    <h1>MineCraft Resource Pack eXtractor (MCRPX)</h1>
    <strong>MCRPX is a client-side web application to extract files from Minecraft: Java Edition resource packs. It can also bypass corrupted resource packs, used by servers to protect their resource packs.</strong><br><br>

## How to use
You can find the web application [here](https://mcrpx.xyz) or you can use it locally.

## How it works
Minecraft resource pack protection typically functions by intentionally corrupting file headers, checksums, and other metadata. This tool bypasses these integrity checks to generate repaired, fully extractable ZIP archives with restored internal content.

Despite the fact that this tool allows extracting corrupted resource packs, please note that the content may be subject to copyright. Use this tool at your own risk.
